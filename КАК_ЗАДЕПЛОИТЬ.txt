Деплой БЕЗ Terminal.app (лучший способ)
=======================================

1) Finder → Projects/BOT/web_kp

2) Двойной клик:  Test-SSH.applescript
   (если спросит приложение — «Сценарии» / Script Editor → Открыть)

3) Потом двойной клик:  Deploy-KP.applescript
   Ждите 1–5 минут, появится «Готово».

---
Старый способ (.command — нужен Terminal.app):

2) Сначала двойной клик:  Test SSH.command
   (если macOS спрашивает — ПКМ → Открыть → Открыть)
   Введите пароль root в окошке.

3) Потом двойной клик:  Deploy KP.command
   Дождитесь окна «Готово» → Safari откроет сайт → Cmd+Shift+R

Логи при ошибке: /tmp/kp-deploy-*.log

---
Если .command не запускается:
Системные настройки → Конфиденциальность → Автоматизация / Полный доступ к диску
или ПКМ по файлу → Открыть (один раз).

---
Терминал в Cursor (если Terminal.app сломан):
View → Terminal  или  Ctrl+`

В чате Cursor можно написать: «задеплой web_kp» — агент запустит скрипт сам.
