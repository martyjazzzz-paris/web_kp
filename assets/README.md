# Ассеты для генератора КП

Положите сюда файлы с прежнего компьютера:

| Файл | Назначение |
|------|------------|
| `BEZ.pdf` | Бланк КП «с шапкой» (шаблон `with_header`) |
| (опционально) | Логотип/подпись/печать можно держать в `../static/` |

Переменные окружения (см. `web_kp/.env.example`):

- `KP_TEMPLATE_BEZ_PATH` — путь к PDF-бланку (по умолчанию `web_kp/assets/BEZ.pdf`)
- `KP_LOGO_FALLBACK_PATHS` — доп. пути к логотипу через `:` (macOS/Linux) или `;` (Windows)
